# Identificador de Artistas

*Hecho por: Nicolás Galetto*

---

## Descripción

Este programa de línea de comandos recibe un enlace de una imagen publicada en internet y obtiene la publicación más antigua de dicha imagen. De esta forma, puedes darle el crédito al artista que se lo merece.

## Uso

```bash
python3 main.py <enlace>
```
